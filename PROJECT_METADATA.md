# Project information needed

The photographs are already on the website. What is missing is the information
that says what each one **is**.

Everything below is optional except the first three. A job with only a title,
a photograph and a service still makes a good entry — the page renders what it
is given and leaves out what it is not. **Nothing here may be estimated.** If a
tonnage is not in the records, leave it blank rather than rounding.

Fill in one block per job and send it back. Adding them to the site is typing.

---

## One block per job

```
Job title             (required)  e.g. "Warehouse portal frame"
Photographs           (required)  which pictures are this job — describe them
                                  or number them from the ones already sent
Services involved     (required)  structural steel / roofing / laser cutting /
                                  fabrication / balustrades / cranage

Client or site name               only if we may publish it
  — or, if not —
Anonymous descriptor              e.g. "a Harare logistics operator"

Location                          town or suburb
Year
Building type                     warehouse, poultry house, workshop, retail…
Scope                             one sentence on what we did
Description                       two or three sentences, no more

Figures — whatever is known, leave the rest blank:
  Clear span
  Eaves height
  Floor area
  Steel tonnage
  Roof area
  Anything else worth stating

Worth mentioning                  one line each — tight access, short
                                  programme, work done around an operating
                                  plant, an unusual detail
```

---

## Things to decide before sending

**Can we name the client?** If there is any doubt, use the anonymous
descriptor. "A Harare logistics operator, Msasa, 2024" is credible and safe.
A named client without permission is not.

**Which photographs belong together?** Several pictures of the same job make a
much stronger entry than one picture each of several jobs.

**Which jobs are worth showing?** Four or five good ones beat a dozen thin
ones. The best candidates are jobs where the building is finished, the
photograph is clear, and there is something specific to say about it.

---

## What happens to it

Each block becomes one entry in `content/projects.js`. The `/projects` page,
the navigation link, the sitemap entry and the structured data all appear
automatically as soon as the first entry is added — the page is built and
tested, it is simply empty.

Until then there is no Projects page and no link to one, which is correct: an
empty portfolio is better than an invented one.
